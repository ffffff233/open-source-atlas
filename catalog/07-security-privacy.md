# 安全与隐私

搜索依据：security、privacy、scanner、secret-scanning、proxy。

这个分区适合学习安全扫描、代理调试、密钥发现、隐私产品和安全工具工程。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [nmap/nmap](https://github.com/nmap/nmap) | 网络发现和安全扫描工具 | 协议探测、扫描引擎、脚本系统 | 想学网络安全工具的人 |
| [zaproxy/zaproxy](https://github.com/zaproxy/zaproxy) | Web 安全测试代理 | 代理架构、被动扫描、插件机制 | 想学 Web 安全测试的人 |
| [projectdiscovery/nuclei](https://github.com/projectdiscovery/nuclei) | 模板驱动的安全扫描器 | 模板引擎、并发扫描、规则组织 | 想做自动化检查工具的人 |
| [trufflesecurity/trufflehog](https://github.com/trufflesecurity/trufflehog) | 密钥泄露扫描工具 | 规则检测、数据源适配、结果验证 | 想学代码安全审计的人 |
| [gitleaks/gitleaks](https://github.com/gitleaks/gitleaks) | Git 仓库密钥扫描工具 | Git 历史遍历、规则匹配、CI 集成 | 想做安全流水线的人 |
| [mitmproxy/mitmproxy](https://github.com/mitmproxy/mitmproxy) | 交互式 HTTP 代理 | 流量拦截、脚本扩展、TLS 处理 | 想学代理和调试工具的人 |
| [dani-garcia/vaultwarden](https://github.com/dani-garcia/vaultwarden) | 自托管密码管理服务 | 认证、加密数据、服务兼容性 | 想做隐私产品的人 |
| [signalapp/Signal-Android](https://github.com/signalapp/Signal-Android) | Signal Android 客户端 | 端到端加密产品、移动端结构 | 想读隐私通信应用的人 |
