# 数据与数据库

搜索依据：database、analytics、search-engine、data-pipeline、postgres。

这个分区适合学习数据库内核、分析系统、缓存、搜索、数据管道和数据产品。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [postgres/postgres](https://github.com/postgres/postgres) | 关系型数据库 | 查询优化、事务、存储引擎 | 想学数据库内核的人 |
| [valkey-io/valkey](https://github.com/valkey-io/valkey) | 内存键值数据库 | 事件循环、数据结构、持久化 | 想学高性能服务的人 |
| [ClickHouse/ClickHouse](https://github.com/ClickHouse/ClickHouse) | 实时分析数据库 | 列式存储、查询执行、分布式分析 | 想学 OLAP 系统的人 |
| [duckdb/duckdb](https://github.com/duckdb/duckdb) | 嵌入式分析数据库 | 向量化执行、文件读取、单机分析 | 想学轻量分析引擎的人 |
| [apache/airflow](https://github.com/apache/airflow) | 数据工作流调度平台 | DAG、调度器、插件和执行器 | 想做数据平台的人 |
| [dbt-labs/dbt-core](https://github.com/dbt-labs/dbt-core) | 数据转换和建模工具 | SQL 编译、模型依赖、数据工程流程 | 想学现代数据栈的人 |
| [opensearch-project/OpenSearch](https://github.com/opensearch-project/OpenSearch) | 搜索和分析引擎 | 索引、查询、分布式搜索 | 想学搜索系统的人 |
| [meilisearch/meilisearch](https://github.com/meilisearch/meilisearch) | 面向应用的搜索引擎 | 易用 API、索引更新、查询体验 | 想做搜索产品的人 |
