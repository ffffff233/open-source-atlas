# 游戏与图形

搜索依据：game-engine、graphics、rendering、2d、3d。

这个分区适合学习游戏引擎、渲染、图形库、编辑器和互动创作工具。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [godotengine/godot](https://github.com/godotengine/godot) | 2D 和 3D 游戏引擎 | 场景系统、编辑器、渲染管线 | 想学游戏引擎的人 |
| [bevyengine/bevy](https://github.com/bevyengine/bevy) | Rust 数据驱动游戏引擎 | ECS、插件、调度系统 | 想学现代游戏架构的人 |
| [raysan5/raylib](https://github.com/raysan5/raylib) | 简洁的游戏编程库 | 图形 API 封装、示例组织、低门槛设计 | 想快速做游戏的人 |
| [cocos/cocos-engine](https://github.com/cocos/cocos-engine) | 跨平台游戏引擎 | 引擎结构、编辑器配合、移动平台 | 想看商业化游戏引擎的人 |
| [pixijs/pixijs](https://github.com/pixijs/pixijs) | Web 2D 渲染引擎 | 渲染抽象、纹理管理、Canvas 体验 | 想做 Web 互动的人 |
| [mrdoob/three.js](https://github.com/mrdoob/three.js) | Web 3D 图形库 | 场景图、材质、几何体、渲染器 | 想学 Web 3D 的人 |
| [BabylonJS/Babylon.js](https://github.com/BabylonJS/Babylon.js) | Web 游戏和渲染引擎 | 引擎 API、工具链、WebGPU 方向 | 想做浏览器 3D 应用的人 |
| [blender/blender](https://github.com/blender/blender) | 3D 创作软件 | 大型桌面软件、渲染、编辑器架构 | 想读复杂图形应用的人 |
