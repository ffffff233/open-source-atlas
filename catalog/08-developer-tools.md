# 开发者工具

搜索依据：cli、developer-tools、editor、terminal、package-manager。

这个分区适合学习编辑器、命令行工具、语言工具链、包管理器和开发体验。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [git/git](https://github.com/git/git) | 分布式版本控制系统 | 对象模型、索引、命令设计 | 想理解版本控制的人 |
| [neovim/neovim](https://github.com/neovim/neovim) | 可扩展文本编辑器 | 插件系统、编辑器核心、LSP 集成 | 想做编辑器工具的人 |
| [microsoft/vscode](https://github.com/microsoft/vscode) | 代码编辑器 | 扩展系统、工作区、前端大型应用 | 想看复杂桌面产品的人 |
| [rust-lang/rust](https://github.com/rust-lang/rust) | Rust 语言和编译器 | 编译器组织、标准库、工具链 | 想学语言实现的人 |
| [denoland/deno](https://github.com/denoland/deno) | JavaScript 和 TypeScript 运行时 | 权限模型、运行时、工具集成 | 想学现代运行时的人 |
| [pnpm/pnpm](https://github.com/pnpm/pnpm) | JavaScript 包管理器 | 依赖解析、存储布局、工作区 | 想学包管理的人 |
| [cli/cli](https://github.com/cli/cli) | GitHub 官方命令行工具 | API 封装、交互体验、认证流程 | 想做 CLI 产品的人 |
| [junegunn/fzf](https://github.com/junegunn/fzf) | 命令行模糊查找器 | 终端交互、搜索算法、性能优化 | 想做高质量终端工具的人 |
