# 后端服务

搜索依据：backend、api、web-framework、server、system-design。

这个分区适合学习 API 框架、服务端结构、数据库交互、认证和后端工程化。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [fastapi/fastapi](https://github.com/fastapi/fastapi) | Python API 框架 | 类型驱动 API、依赖注入、文档生成 | 想写现代 Python 后端的人 |
| [django/django](https://github.com/django/django) | Python 全功能 Web 框架 | ORM、管理后台、应用组织 | 想学成熟后端框架的人 |
| [rails/rails](https://github.com/rails/rails) | Ruby Web 应用框架 | 约定优于配置、ORM、脚手架 | 想学高生产力后端的人 |
| [spring-projects/spring-boot](https://github.com/spring-projects/spring-boot) | Java 服务开发框架 | 自动配置、企业集成、启动流程 | 想看企业级 Java 工程的人 |
| [gin-gonic/gin](https://github.com/gin-gonic/gin) | Go Web 框架 | 路由、中间件、轻量服务结构 | 想学 Go API 的人 |
| [nestjs/nest](https://github.com/nestjs/nest) | Node.js 服务框架 | 模块化、依赖注入、控制器设计 | 想写结构化 TypeScript 后端的人 |
| [laravel/framework](https://github.com/laravel/framework) | PHP Web 框架 | ORM、队列、服务容器、开发体验 | 想理解完整 Web 框架的人 |
| [pocketbase/pocketbase](https://github.com/pocketbase/pocketbase) | 单文件实时后端 | 嵌入式数据库、认证、实时 API | 想做小型后端产品的人 |
