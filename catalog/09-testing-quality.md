# 测试与质量

搜索依据：testing、browser-testing、unit-test、automation、load-testing。

这个分区适合学习测试框架、浏览器自动化、单元测试、端到端测试和压测。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [pytest-dev/pytest](https://github.com/pytest-dev/pytest) | Python 测试框架 | 插件机制、fixture、断言改写 | 想学测试框架的人 |
| [microsoft/playwright](https://github.com/microsoft/playwright) | 浏览器测试和自动化框架 | 多浏览器抽象、等待机制、测试运行器 | 想做 E2E 测试的人 |
| [cypress-io/cypress](https://github.com/cypress-io/cypress) | Web 应用测试工具 | 浏览器内测试、调试体验、运行器 | 想做前端测试平台的人 |
| [vitest-dev/vitest](https://github.com/vitest-dev/vitest) | Vite 生态测试框架 | 快速运行、模拟、覆盖率集成 | 想做前端单测的人 |
| [jestjs/jest](https://github.com/jestjs/jest) | JavaScript 测试框架 | 快照测试、运行调度、Mock 系统 | 想学 JS 测试生态的人 |
| [junit-team/junit5](https://github.com/junit-team/junit5) | Java 测试框架 | 扩展模型、测试引擎、断言组织 | 想学 Java 测试的人 |
| [SeleniumHQ/selenium](https://github.com/SeleniumHQ/selenium) | 浏览器自动化标准实现 | WebDriver、跨语言绑定、远程执行 | 想理解浏览器自动化的人 |
| [locustio/locust](https://github.com/locustio/locust) | Python 压测工具 | 用户模型、分布式压测、结果展示 | 想学性能测试的人 |
