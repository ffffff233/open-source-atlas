# 文档与知识管理

搜索依据：documentation、knowledge-base、notes、wiki、docs-site。

这个分区适合学习文档站、知识库、笔记产品、写作工具和信息组织。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [mkdocs/mkdocs](https://github.com/mkdocs/mkdocs) | 静态文档站生成器 | Markdown 管线、主题、插件 | 想做文档工具的人 |
| [sphinx-doc/sphinx](https://github.com/sphinx-doc/sphinx) | Python 文档系统 | 文档解析、扩展、交叉引用 | 想学大型文档系统的人 |
| [facebook/docusaurus](https://github.com/facebook/docusaurus) | 文档网站框架 | 版本化文档、主题、内容路由 | 想做开发者文档站的人 |
| [readthedocs/readthedocs.org](https://github.com/readthedocs/readthedocs.org) | 文档托管平台 | 构建服务、项目管理、托管流程 | 想做平台型文档服务的人 |
| [logseq/logseq](https://github.com/logseq/logseq) | 本地优先知识管理工具 | 块编辑、双链、同步模型 | 想做笔记产品的人 |
| [outline/outline](https://github.com/outline/outline) | 团队知识库 | 权限、协作编辑、文档组织 | 想做团队工具的人 |
| [rust-lang/mdBook](https://github.com/rust-lang/mdBook) | 面向书籍的文档生成器 | 章节组织、渲染、命令行体验 | 想写技术书和课程的人 |
| [tldr-pages/tldr](https://github.com/tldr-pages/tldr) | 命令行示例文档集合 | 社区维护、短文档格式、索引 | 想做知识整理项目的人 |
