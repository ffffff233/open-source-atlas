# 云原生与运维

搜索依据：devops、kubernetes、observability、infrastructure、ci。

这个分区适合学习容器编排、发布系统、监控、网关、基础设施自动化和运维工具。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [kubernetes/kubernetes](https://github.com/kubernetes/kubernetes) | 容器编排平台 | 控制器、调度、声明式 API | 想理解云原生核心的人 |
| [opentofu/opentofu](https://github.com/opentofu/opentofu) | 基础设施即代码工具 | 状态管理、资源图、Provider 模型 | 想学基础设施自动化的人 |
| [ansible/ansible](https://github.com/ansible/ansible) | 自动化配置和部署工具 | 模块系统、远程执行、任务编排 | 想学运维自动化的人 |
| [helm/helm](https://github.com/helm/helm) | Kubernetes 应用包管理器 | 模板渲染、发布版本、Chart 结构 | 想管理云原生应用的人 |
| [argoproj/argo-cd](https://github.com/argoproj/argo-cd) | GitOps 持续交付系统 | 应用同步、状态对比、控制循环 | 想学发布平台的人 |
| [prometheus/prometheus](https://github.com/prometheus/prometheus) | 监控和时序数据系统 | 抓取模型、查询语言、告警流程 | 想学可观测性的人 |
| [grafana/grafana](https://github.com/grafana/grafana) | 可观测性和数据面板平台 | 插件系统、面板编辑器、数据源 | 想做平台型产品的人 |
| [open-telemetry/opentelemetry-collector](https://github.com/open-telemetry/opentelemetry-collector) | 遥测数据采集器 | 接收器、处理器、导出器流水线 | 想学标准化观测数据的人 |
