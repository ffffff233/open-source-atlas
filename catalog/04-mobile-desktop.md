# 移动与桌面

搜索依据：mobile、desktop、cross-platform、electron、flutter、tauri。

这个分区适合学习跨平台 UI、桌面应用壳、移动端工具链和端侧产品体验。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [flutter/flutter](https://github.com/flutter/flutter) | 跨平台 UI 框架 | 渲染管线、组件系统、平台适配 | 想做跨端应用的人 |
| [facebook/react-native](https://github.com/facebook/react-native) | 使用 React 构建原生应用 | 桥接机制、原生模块、跨端渲染 | 想学移动跨端的人 |
| [expo/expo](https://github.com/expo/expo) | React Native 应用平台 | 工具链、构建发布、模块封装 | 想提升移动开发效率的人 |
| [electron/electron](https://github.com/electron/electron) | 使用 Web 技术构建桌面应用 | 多进程模型、系统接口、打包 | 想做桌面客户端的人 |
| [tauri-apps/tauri](https://github.com/tauri-apps/tauri) | Rust 与 Web 的轻量桌面框架 | 安全边界、原生能力、体积控制 | 想做轻量桌面应用的人 |
| [ionic-team/ionic-framework](https://github.com/ionic-team/ionic-framework) | Web 技术跨端 UI 框架 | 移动组件、平台适配、手势体验 | 想做混合应用的人 |
| [fastlane/fastlane](https://github.com/fastlane/fastlane) | 移动应用构建和发布自动化 | 发布流程、证书处理、CI 集成 | 想学移动工程化的人 |
| [AppFlowy-IO/AppFlowy](https://github.com/AppFlowy-IO/AppFlowy) | 开源协作工作区应用 | 产品结构、跨端 UI、本地数据 | 想读真实端侧产品的人 |
