# AI 与机器学习

搜索依据：machine-learning、llm、inference、vector-database、deep-learning。

这个分区适合学习模型框架、推理服务、向量检索、训练生态和 LLM 应用工程。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [tensorflow/tensorflow](https://github.com/tensorflow/tensorflow) | 面向机器学习的大型计算框架 | 跨语言绑定、算子组织、训练运行时 | 想理解深度学习框架的人 |
| [pytorch/pytorch](https://github.com/pytorch/pytorch) | Python 优先的深度学习框架 | 动态图、张量实现、GPU 加速接口 | 想读大型 Python 与 C++ 混合项目的人 |
| [huggingface/transformers](https://github.com/huggingface/transformers) | 多模态模型和预训练模型生态 | 模型抽象、配置系统、推理管线 | 想做 LLM 应用和模型调用的人 |
| [ollama/ollama](https://github.com/ollama/ollama) | 本地运行大语言模型的工具 | 模型分发、本地服务、命令行体验 | 想做本地 AI 工具的人 |
| [vllm-project/vllm](https://github.com/vllm-project/vllm) | 高吞吐 LLM 推理引擎 | 推理调度、显存管理、服务接口 | 想学模型服务性能优化的人 |
| [milvus-io/milvus](https://github.com/milvus-io/milvus) | 向量数据库 | 向量索引、分布式存储、检索服务 | 想做 RAG 和语义检索的人 |
| [rasbt/LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch) | 从零实现 LLM 的学习项目 | 训练流程、Transformer 结构、可读代码 | 想补模型底层的人 |
| [microsoft/ML-For-Beginners](https://github.com/microsoft/ML-For-Beginners) | 机器学习入门课程 | 教学组织、数据案例、基础算法 | 想系统入门机器学习的人 |
