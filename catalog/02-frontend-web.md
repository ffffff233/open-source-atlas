# 前端 Web

搜索依据：frontend、react、vue、web-framework、component、build-tool。

这个分区适合学习 UI 框架、组件设计、构建工具、前端应用架构和工程化。

| 项目 | 做什么 | 适合看什么 | 适合谁 |
| --- | --- | --- | --- |
| [facebook/react](https://github.com/facebook/react) | Web 和原生 UI 的组件库 | 协调机制、组件模型、包结构 | 想深入前端框架的人 |
| [vuejs/core](https://github.com/vuejs/core) | Vue 3 核心框架 | 响应式系统、编译器、运行时设计 | 想学渐进式框架实现的人 |
| [sveltejs/svelte](https://github.com/sveltejs/svelte) | 编译型前端框架 | 编译时优化、语法转换、状态模型 | 想理解编译型 UI 的人 |
| [angular/angular](https://github.com/angular/angular) | 大型前端应用框架 | 模块系统、依赖注入、工具链组织 | 想看企业级前端框架的人 |
| [vercel/next.js](https://github.com/vercel/next.js) | React 全栈应用框架 | 路由、渲染模式、构建服务 | 想做现代 Web 应用的人 |
| [vitejs/vite](https://github.com/vitejs/vite) | 前端开发服务器和构建工具 | 插件系统、开发体验、打包集成 | 想学前端工具链的人 |
| [tailwindlabs/tailwindcss](https://github.com/tailwindlabs/tailwindcss) | 原子化 CSS 工具 | 设计 token、扫描生成、插件机制 | 想做设计系统和样式工具的人 |
| [storybookjs/storybook](https://github.com/storybookjs/storybook) | 组件开发与文档工作台 | 插件架构、组件隔离、文档生成 | 想做组件库的人 |
