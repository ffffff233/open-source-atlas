# Submission Policy

本文件说明 Open Source Atlas 的收录和推广边界。

## 可以收录

- 合法开源项目。
- 正常商业化项目。
- 有明确许可证、维护状态和项目边界的仓库。
- 能帮助读者学习工程能力、产品能力、交付能力或运营能力的项目。
- 电商、CRM、客服、计费、数据分析、自动化、文档、开发工具、云原生和安全防护类项目。

## 可以推广

项目方可以把 GitHub 仓库链接、项目介绍、许可证、维护状态和希望展示的理由发送到 denget2026@163.com。

维护者会审核项目真实性、合法性、代码质量、维护状态和读者价值。

通过审核后，项目可能被加入对应分类或后续重点展示。

## 明确不收

- 诈骗、盗号、撞库、钓鱼、赌博和洗钱相关项目。
- 侵权盗版、破解付费软件、绕过授权和绕过风控项目。
- 恶意采集、垃圾营销、黑灰产导流和账号买卖项目。
- 恶意软件、隐蔽控制、未经授权的数据窃取项目。
- 主要用途不清楚，或者项目描述和实际代码明显不一致的仓库。

## 审核原则

- 先看项目真实用途。
- 再看许可证和维护状态。
- 再看代码可读性和学习价值。
- 最后看是否适合当前分类。

提交申请不代表自动收录，也不代表自动推广。
